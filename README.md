# VolSync

> 一个 Windows 小工具：**把系统"主音量"实时同步到各个应用的会话音量**，用于解决「某些机器上系统音量条对内置扬声器无效、只有静音位管用」的问题。

## 背景 / 原理

Windows 调音量分两层：

1. **软件音量** —— 音频引擎对采样乘增益（"音量合成器"里逐 App 的那条）。
2. **硬件音量** —— 若驱动在拓扑里暴露 `KSNODETYPE_VOLUME` 节点，**系统主音量就走这个硬件节点**。

部分 Intel SST + Realtek UAD 的笔记本上，**内置扬声器这一路的硬件音量节点存在但增益不生效**，于是：

- 系统主音量条 → 无效（只走坏掉的硬件节点）
- 逐 App 音量 / 软件音量 → 有效
- 耳机（另一路硬件音量正常）→ 正常

本工具不去修硬件节点，而是**利用仍然有效的软件层**：监听端点主音量数值，实时把它写进所有应用的会话音量。这样拖动系统音量条 / Fn 音量键时，响度会真实变化。

## 编译

需要 Windows 自带的 .NET Framework 编译器（无需安装额外 SDK）：

```
build.cmd
```

或手动：

```
C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe /nologo /target:winexe /out:VolSync.exe src\VolSync.cs
```

## 使用

```
VolSync.exe
```

后台静默运行即可（无窗口程序）。

**开机自启**：在启动文件夹（`Win+R` → `shell:startup`）放一个指向 `VolSync.exe` 的快捷方式。

## 局限与备注

- 本工具通过"镜像"实现，属于曲线救国；**当你改变主音量时，会把所有 App 的会话音量统一设为该值**，因此会覆盖你在音量合成器里对单个 App 的单独微调。
- 不修改驱动、系统设置或注册表，随时可关可卸（删除启动快捷方式 + 结束进程即可）。
- 若要"原生根治"，可用过滤驱动隐藏坏的 `KSNODETYPE_VOLUME` 节点（例如 WinSoftVol），但内核驱动需要微软签名 / 测试签名模式。
